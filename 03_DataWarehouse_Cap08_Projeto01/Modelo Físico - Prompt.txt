
O que é um modelo físico na implementação de um Data Warehouse?

A partir deste modelo lógico abaixo, crie um modelo físico para o SGBD PostgreSQL;

Tabela Dim_Produto

•	Produto_ID (PK) - INT
•	Nome - VARCHAR(255)
•	Categoria - VARCHAR(255)

Tabela Dim_Canal 

•	Canal_ID (PK) - INT
•	Nome - VARCHAR(255)
•	Região - VARCHAR(255)

Tabela Dim_Data

•	Data_ID (PK) - INT
•	Dia - INT
•	Mês - INT
•	Ano - INT
•	Data_Completa - DATE

Tabela Dim_Cliente

•	Cliente_ID (PK) - INT
•	Nome - VARCHAR(255)
•	Tipo - VARCHAR(255)
•	Cidade - VARCHAR(255)
•	Estado - VARCHAR(50)
•	País - VARCHAR(255)

Tabela Fato_Venda

•	Produto_ID (FK) - INT
•	Canal_ID (FK) - INT
•	Data_ID (FK) - INT
•	Cliente_ID (FK) - INT
•	Valor - DECIMAL(10, 2)
•	Quantidade - INT

Cada Venda está associada a um Produto, um Canal de Venda, uma Data e um Cliente através das chaves estrangeiras Produto_ID, Canal_ID, Data_ID e Cliente_ID, respectivamente.
