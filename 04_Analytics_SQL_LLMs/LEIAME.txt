 ::: OBJETIVO DO LABORATÓRIO :::

 - Executar uma atividade típica de engenharia analítica unindo engenharia de dados e análise de dados no mesmo projeto. 
 
 - Para isso usaremos Inteligência Artificial através de LLMs(Large Language Model), Linguagem Python e Linguagem SQL.

 - Criaremos um único pipeline que vai carregar os dados em um banco de dados usando Linguagem Python, extrair um resumo dos dados carregados usando Linguagem SQL, entregar esse resumo a um LLM, que então irá fazer uma análise completa sobre o padrão de compra dos clientes, entregando um relatório    completo    com    análise,    comparação,    tendências    e recomendações.
