==== SUPER PROJETO DE PYSPARK PARA PROCESSAMENTO DISTRIBUÍDO DE DADOS ====

Na pasta de Jobs desse projeto, tem 51 scripts diferentes, super ricos em informação de pyspark.
Inclui manipulação de dados, criação de pipelines, etc...

Extremamente útil para consultas e para usar como base para outros scripts.

#Estrutura do Projeto:

Extração, Limpeza e Transformação de dados: PySpark
Banco de dados: SQLite

Se conecta com SQLlite via JDBC

Pasta /dados:
.json -> dados de origem
.db -> dados de destino
.jar -> conexão jdbc

Pasta /jobs:
.py -> script da pipeline
